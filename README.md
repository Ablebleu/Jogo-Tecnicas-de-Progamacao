# Aventura Alienada

Jogo desenvolvido em dupla em C++ com SFML 3.1 como projeto de programação, com pacote executável pronto para teste na aba **Releases**.

## Como executar
1. Vá até a aba **Releases** deste repositório e baixe o arquivo `.zip` da versão mais recente (`v1.0`).
2. Extraia o conteúdo do `.zip` em uma pasta no seu computador.
3. Execute o arquivo `.exe` dentro da pasta extraída (já acompanha as DLLs necessárias de Release, a pasta `assets` e o `save.json`).

## Controles
- **W, A, D:** movimento
- **S:** ataque
- **ESC:** menu de pausa (útil caso o jogador morra)

## Especificações usadas no desenvolvimento
- **Sistema Operacional:** Windows 11
- **IDE:** Microsoft Visual Studio 2026
- **Compilador:** MSVC (Microsoft C++ Build Tools — Conjunto de Ferramentas da Plataforma v145)
- **Padrão da linguagem:** ISO C++17 (`/std:c++17`)
- **Biblioteca gráfica:** SFML 3.1
